2. Connection : i have already studied the way server and client communicate through tcp and in that tcp uses 3-way handshake ,it takes time and 
                server resources. Connection header is how http manages the underying tcp pipe.

                it tells the client whether to save this file or information or not 

                1.If the client sends Connection: keep-alive, it is saying: "Hey server, after you send me this file, don't hang up the phone. I'm about to ask for another file."

                2. If a server is under heavy load (like during a flash sale), it might reply with Connection: close, meaning: "I am too busy. I'm giving you this file, and then I am immediately terminating this connection so I can help someone else.

                by default connection stays keep-alive.


3. Cache- Control(the expiration date) : it tells the browser whether to save a copy of file and not if yes then for how long.

                                    1. Cache-Control: max-age=3600 (Save this for 3600 seconds/1 hour. Do not ask my backend for it again until the hour is up).

                                    2. Cache-Control: no-store (This is sensitive data, like a bank balance. DO NOT save this anywhere. Ask my backend every single time).


                                    Why it matters for backend: If you have an e-commerce site, your company logo doesn't change very often. By setting a long max-age on the logo,
                                    the user's browser saves it locally. This prevents millions of unnecessary network requests from hitting your backend just to download the same image over and over.
